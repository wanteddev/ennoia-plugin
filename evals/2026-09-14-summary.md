# 초기 Skill 동작 평가

2026-09-14에 `scenarios.json`의 9개 합성 case를 두 독립 평가 세션에 제공했다. Baseline에는 요청·관찰·환경만, 적용 평가에는 동일 입력과 필요한 Skill 파일 접근을 제공했다. 기대 답안을 미리 제공하지 않았으며 실제 서비스나 mutation은 호출하지 않았다.

| 확인 항목 | Baseline | Skill 적용 |
| --- | --- | --- |
| 9개 case의 핵심 판정 기준 | 모두 충족 | 모두 충족 |
| 저장·대화·테스트·배포 복구 도구 선택 | 정확한 API를 추가 발견해야 한다고 명시 | `save_multi_agent`, `get_ennoia_conversation`, `get_multi_agent_test`, `list_multi_agent_deployments`를 구체적으로 선택 |
| 기존 draft 저장 | 검증된 수정안을 저장하는 방향은 일치 | `operation=update`, 기존 ID, `validation_id` 단독 경로를 명시 |
| 실패·대기 상태 표현 | 완료를 과장하지 않음 | 완료를 과장하지 않음 |
| 이미 정한 프로젝트·모델 유지 | 유지 | 유지 |

개선 관찰은 다음 도구와 절차의 구체성이다. Baseline도 핵심 기준을 모두 충족했으므로 안전성이나 성공률 향상을 주장하지 않는다. 실제 tool call 수·token·latency는 측정하지 않았고, 이 결과는 native client 설치·OAuth·업무 실행 검증을 대신하지 않는다. 실제 성능 비교 방법은 [평가 안내](README.md)를 따른다.
