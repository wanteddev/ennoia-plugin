# 1.0.1 응답 해석·표시 평가

2026-09-15에 `presentation-scenarios.json`의 11개 사례를 기존 1.0.0 Skill과 수정된 1.0.1 Skill에 각각 적용했습니다. 두 독립 모델 평가자는 같은 prompt·observations·environment를 받고 필요한 Skill과 연결된 reference만 읽었습니다. 서로의 답변과 기대 판정 기준은 제공하지 않았습니다. 각 실행은 사례별 답변·다음 행동·읽은 경로를 남겼으며, 평가 후 원본을 대조했습니다.

## 관찰 결과

- 현재 설정·지정 대상·전체 조회·이전 서버·현재 설정 확인 불가·명시적 배포 대상의 6개 사례에서 1.0.0은 그룹·프로젝트 코드를 답변에 함께 표시했습니다. 1.0.1은 이름으로 안내하고 해당 코드를 표시하지 않았습니다.
- 인증 실패 사례의 기존 답변은 잔여 프로젝트 이름과 재인증 필요를 함께 설명했습니다. 수정 후에는 현재 프로젝트를 확인할 수 없다고 안내하고 host 재인증을 선택했습니다. 기존 답변도 인증 성공을 주장하지 않았으므로 인증 오류 방지의 신규 성과로 계산하지 않습니다.
- 현재 설정과 실제 요청 대상의 구분, 이전 서버 응답에서 현재 설정 미확인 처리, 진행 중 상태, 부분 RAG 준비, null 비용·부분 실패·잘림, 전체 App 답변 보존, 중복 배포 승인 방지는 두 실행 모두 적절했습니다. 이 항목은 회귀가 없었음을 확인한 결과입니다.
- 요약과 원본 상태가 충돌하는 사례에서 두 실행 모두 완료를 주장하지 않았습니다. 1.0.1은 요약과 원본의 불일치도 명시했습니다. 두 실행 모두 기존 대화 ID로 재조회하며 지원되지 않는 자동 알림을 약속하지 않았습니다.
- 현재 설정을 직접 요청했지만 응답에 없는 2개 사례는 두 실행 모두 필요한 현재 선택 조회를 다음 행동으로 제안했습니다. 호출 감소로 계산하지 않습니다.
- 수정 후 11개 사례 모두 해당 Skill과 plugin 내부 `references/response-guide.md`를 읽었습니다. 원본 Skill과 공통 reference의 충돌 또는 중요한 동작 회귀는 관찰되지 않았습니다.

## 범위와 제한

각 조건당 한 번의 합성 평가로, 통계적 성공률이나 실제 token·latency 측정이 아닙니다. 실제 Ennoia 도구를 호출하거나 저장·배포하지 않았습니다. native host의 Skill 선택, 설치 cache, MCP 인증·응답 전달은 별도 검증 대상입니다. 원본 모델 출력은 로컬 평가 자료로 보관하며 이 문서는 검토한 결과의 요약입니다.

이전 서버 호환을 유지하면서 [orchestrator #786](https://github.com/wanteddev/llm-orchestrator/pull/786)의 현재 선택 정보와 [MCP server #106](https://github.com/wanteddev/ennoia-mcp-server/pull/106)의 기본 요약·원본 JSON을 해석하도록 구성했습니다. 서버의 선택 보호나 응답 생성 코드를 Plugin에 복제하지 않습니다.
