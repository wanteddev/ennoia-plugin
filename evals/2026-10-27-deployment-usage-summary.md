# 배포 사용 안내 합성 평가 기록

검증 대상은 배포 직후 안내와 새 대화의 재조회, 키 확인 위치, 버전·프로젝트·환경 유지, 개인 인증·승인 상태 미확인, 안내 생성 실패다.

평가자는 [시나리오 12개](deployment-usage-scenarios.json)와 적용되는 Skill/reference만 읽고 답변·다음 행동을 생성했다. 답변 작성 전에 rubric은 제공하지 않았다. 작성자가 이후 [평가 기준](deployment-usage-rubric.md)으로 판정한 결과 12개 모두 기준을 충족했다. 기본 Plugin과의 비교 실행은 하지 않았으므로 개선률·호출 수 감소·성능 개선을 계산하지 않는다.

| 확인 범위 | 결과 |
| --- | --- |
| 배포 직후·새 대화 | 실제 대상의 두 링크, 키 입력 순서, 고정 버전 cURL을 제공하고 실행 미검증을 표시했다. |
| 키 분실·구 서버 | 기존 프로젝트 키 확인 위치를 안내했다. 재배포나 키 발급을 제안하지 않고, 계약이 없는 cURL을 만들지 않았다. |
| 중지·초안·지정 대상·dev | 중지된 버전이나 미배포를 호출 가능으로 바꾸지 않고 실제 대상·환경을 유지했다. |
| 개인 연결·미완료 | 모든 API에 사용자 ID를 요구하지 않았고 미완료 오류만으로 SQL 승인 대기를 확정하지 않았다. |
| 링크와 안내 실패 | credential query 링크를 복제하지 않았다. 배포 성공과 안내 생성 미확인을 구분하고 배포를 재전송하지 않았다. |

관찰은 축약된 합성 입력이다. 실제 계정 로그인, 링크 접근 권한, API 호출·배포, host의 Plugin 설치·Skill 로딩은 검증하지 않았다. 실제 API의 응답 계약은 서버·MCP 테스트와 별도로 판단한다.
